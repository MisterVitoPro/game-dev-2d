# game-dev-2d

A Claude Code plugin marketplace for 2D game development.

Owner: MisterVitoPro

## Plugins

- **pixel-sprite-generator** -- generate square pixel-art sprites from semantic JSON grids +
  palettes (deterministic, no external image model). Hosted at
  [MisterVitoPro/pixel-sprite-generator](https://github.com/MisterVitoPro/pixel-sprite-generator)
  and referenced here via a `github` source.

## Install

```
/plugin marketplace add MisterVitoPro/game-dev-2d
/plugin install pixel-sprite-generator@game-dev-2d
```

Then, in a project, run `/pixel-sprite-generator:init` to scaffold it.
